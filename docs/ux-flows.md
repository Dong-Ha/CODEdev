# Code-Dev UX v0.5 — Impeccable 개선 기록

**목표:** 사람의 직접 개발 요청과 AX 오케스트레이션 요청을 혼동하지 않고, 하나의 제안·검토·승인 프로세스로 연결.

## 문제와 개선

| 우선순위 | 기존 화면/동작 | 사용자 영향 | 개선 |
| --- | --- | --- | --- |
| P1 | 자유 텍스트 요청만 입력 | SRS/SDD/Jira 출처 및 수용 조건이 사라짐 | 요청 근거 선택 + 원문/참조 ID 입력 |
| P1 | 에이전트 인계 지점 없음 | SDD 인계 및 SQE 재작업을 직접 복사해야 함 | 별도 인증 API와 수신함 |
| P1 | Diff에 요청 출처 정보가 없음 | 검토자가 변경 목적을 추적하기 어려움 | 검토 패널에 출처·상위 실행 ID 표시 |
| P2 | 개발 환경 설정이 작업과 분리되어 보임 | 기존 프로젝트 규칙을 잊기 쉬움 | 공통 개발 프로필 상단 유지, 저장 후 변경 차단 규칙 공유 |
| P2 | 빈 수신함의 목적을 알기 어려움 | 다음 행동 불분명 | 빈 상태와 연동 토큰 설정 안내 |
| P2 | 수정 허용 경로를 이미 설정했는데 파일 선택을 다시 요구 | 중복 입력과 불필요한 개발 착수 지연 | 대상 파일을 선택 입력으로 변경하고 허용 경로 기반 자동 선택 지원 |

## 두 가지 작업 흐름

- **직접 요청:** 환경 설정 → 자료 유형 선택 → 필요시 본문/ID 입력 → 변경 요청 (파일 선택은 선택 사항) → 허용 범위 내 자동 파일 선정 → Diff/근거 검토 → 승인 또는 반려 → 되돌리기
- **AX 인계:** 상위 에이전트 API 호출 → `queued`/`generating` → `review` → GUI에서 원문/상위 ID·Diff 확인 → 승인/반려 → API 상태 조회 → 상위 흐름 이어가기

## 주요 상태와 사용자 안내

| 상태 | UI 표시 | 다음 안전한 행동 |
| --- | --- | --- |
| 프로젝트 미설정 | 설정 필요 | 프로젝트 경로·빌드 레시피·허용 경로 저장 |
| 요청 미입력 | 빈 Diff + 작업 요청 입력 | 파일을 지정하지 않아도 직접 요청 가능 |
| 대상 선택 불확실 | 허용 범위 내 파일을 자동 결정하지 못함 | 대상 파일을 선택하거나 환경 설정에서 수정 허용 범위를 좁혀 재시도 |
| 수신 없음 | 수신 작업 없음 | 상위 에이전트 연결 또는 직접 요청으로 전환 |
| 요청 생성 중 | 생성 중 | 기다리는 동안 파일 쓰기 없음 |
| 생성 실패 | 호출·검증 실패 이유 및 CLI 상태 | 환경/인증/요청을 확인하고 재시도 |
| 정상 응답 · 변경 없음 | Claude 응답 요약·판단 근거·대상 파일, 승인 비활성화 | 요청 수정 후 다시 생성 (원본 보존) |
| 검토 준비 | 출처·Diff·검토 체크리스트 | 의도하지 않은 코드 확인, 승인 또는 반려 |
| 적용 완료 | 반영 완료 | 변경 필요 시 되돌리기 |
| 설정 또는 소스 변경 | 서버 충돌 오류 | 새 설정/소스로 변경안을 다시 생성 |

## 미구현 후속 작업

- 비대화형 실행의 종료 상태를 외부 AX 오케스트레이터에 이벤트로 푸시하는 기능
- 여러 파일을 묶은 Patch/worktree 단계 승인
- 다중 사용자 권한과 영구 감사 로그, SLA/재시도 정책

본 문서는 제공된 CODEdev 소스의 UX 검토와 개선에 대한 **설계 기록**이며 실제 사용자 조사 결과는 아닙니다.

## 프로젝트 파일 검색 UX

- `Project Root`가 모든 수정 허용 경로의 기준이며, 빌드 작업 디렉터리 설정은 검색 기준에 영향을 주지 않습니다.
- 허용 경로의 와일드카드 이전 고정 폴더를 먼저 탐색합니다. 허용되지 않은 `arch/` 등의 파일은 수정 허용 목록 한도에 포함하지 않습니다. 한도(현재 10,000개)를 넘으면 누락 사실을 표시합니다.
- GUI는 탐색 후보 수와 실제 허용 파일 수를 별도로 보여줍니다. 제한 도달 또는 설정 경로 누락 시 명시적으로 안내합니다.
- 탐색 제한이 있으면 자동 대상 선택을 중단하고 허용 경로 규칙을 재검토하도록 안내합니다. 파일을 직접 선택하는 UI는 없습니다.
- 수정 허용 패턴에 매칭되는 일반 파일은 64KB를 초과해도 탐색 목록에 포함됩니다. 64KB 초과 텍스트 파일은 구간 교체 변경안을 생성하며, 8MB 초과나 바이너리 파일은 목록에 표시하되 변경안 생성 시 처리 제한을 설명합니다. 숨김/빌드 폴더, 심볼릭 링크 및 명시적인 수정 제외 경로는 보안 경계를 유지합니다.
