# Code-Dev Request Studio UX

## 주 작업

개발자는 환경과 수정 가능한 파일을 지정하고, SDD·Jira·자유 요청을 입력해 미래의 code-dev agent가 사용할 작업을 준비합니다. 실제 code-dev agent 구현은 별도 단계입니다. 현재 UI는 요청과 환경을 Claude CLI에 직접 전달하고 텍스트 응답을 표시하며, 이를 코드 개발/승인 완료로 표시하지 않습니다.

1. **개발 환경**: 서버 기준 경로 연결 → 개발 OS/도구/대상 환경 입력 → 빌드 방법과 수정 파일 경로 저장 → 실제 허용 파일 확인.
2. **요청 작성**: 요청 근거와 본문/출처, 개발 요청 입력 → 우측 개발 조건 확인 → Claude Code로 바로 전달 또는 접수만 하기.
3. **접수 내역**: 직접/에이전트 요청 필터 → 접수 당시 전달 내용과 실제 프롬프트 확인 → 전송/응답/오류 확인 → 필요하면 재전송 또는 JSON 다운로드.

다른 에이전트의 API 요청도 같은 내역에 보관합니다. 요청은 재시작 후 유지되며 선택한 프로젝트의 항목만 GUI에 표시합니다.

## 상태와 복구

| 상태 | 표시 / 다음 행동 |
| --- | --- |
| 첫 실행 | 실제 경로 연결 또는 샘플 연결 |
| 미저장 변경 | 상태 배지와 저장 안내, 요청 작성/접수 차단 |
| 다른 탭에서 설정 수정 | 409 오류, 경로를 다시 연결해 새 설정 확인 |
| 허용 파일 없음 / 탐색 제한 | 저장된 파일 탐색 경고, 허용 경로 수정 후 접수 |
| 접수만 하기 | 전송 대기, 아직 CLI 호출 없음 |
| CLI 전달 | 전송 대기/응답 중 상태 자동 조회, 같은 프로젝트 중복 실행 차단 |
| CLI 응답 수신 | 최종 텍스트 응답과 공개 실행 이벤트 표시, 재전송 가능 |
| CLI 미설치/실패 | 설치·인증 확인 및 CLI 상태 새로고침, 입력/접수 기록 유지 |
| 서버 재시작 중단 | 완료 여부 불명으로 표시, 자동 재전송 금지 |
| 통신 오류 / 중복 클릭 | 오류 표시, 입력 유지, 동일 내용 재시도 시 같은 idempotency key |
| 접수 후 환경 변경 | 과거 스냅샷 유지, 재접수 필요, 에이전트 상세 읽기 차단 |
| 요청 없음 | 요청 작성에서 시작하도록 안내 |
| 에이전트 API 비활성화 | AX_AGENT_TOKEN 설정 안내, 직접 요청은 이용 가능 |
| 저장 오류 | 성공 표시 금지, 서버 오류 안내, 입력 보존 |

## 구현 기준

- 파일은 전체 경로 문자열과 검색/더 보기로 확인합니다. 개별 파일 지정과 glob을 모두 지원합니다.
- 기존 설정을 새 프로필로 읽을 때 신규 환경 정보는 빈 값으로 취급합니다. 과거 요청을 현재 프로필로 덮어쓰지 않습니다.
- 모든 요청/원문/경로를 textContent로 표시합니다. JSON은 펼쳐 보기와 다운로드로 제공합니다.
- 입력 필드에 label, 내비게이션에 aria-current, 접수 목록에 aria-pressed를 둡니다. 상태/오류는 live region에 알립니다.
- 좁은 화면에서는 환경 폼과 요청/내역을 단일 열로 배치합니다.
- 향후 agent adapter, 작업 인수/결과 상태, 코드 변경 검토는 후속 구현입니다.
